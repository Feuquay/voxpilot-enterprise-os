# Exact Setup From iPhone

## Deploy
1. Unzip this package in the iPhone Files app.
2. Create `voxpilot-chairman` on GitHub.
3. Upload all package contents to the repository root.
4. In GitHub: **Settings → Pages → Source → GitHub Actions**.
5. Run the included Pages workflow.
6. Open the deployed address in Safari.
7. Use **Share → Add to Home Screen**.

## Initialize
The first launch asks for the Founder name, GitHub username, and repository name.

## Live AI
Create a fine-grained GitHub token with `Models: read`, then enter it under Chairman Settings.

## Cloud continuity
Give a narrowly scoped token access only to `voxpilot-chairman` with `Contents: read and write`. Choose a strong passphrase and use **Encrypted Backup**.

Never commit tokens or passphrases into repository files.
